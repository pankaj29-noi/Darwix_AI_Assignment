# Pankaj Bishnoi — Darwix AI Assignment

Unzip this folder anywhere. The project runs on the computer where it is unzipped. A `localhost` link from another computer will not open it.

## Mac or Linux

```bash
chmod +x setup.sh run.sh
./setup.sh
./run.sh
```

## Windows

Double-click `setup.bat`, then double-click `run.bat`.

## Open the system

- App: http://127.0.0.1:5173
- API: http://127.0.0.1:8000/health

The first setup needs internet once, to install Python and Node packages. After that, the demo runs locally in mock mode. No API key is required.
